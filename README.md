# Портфолио по автоматизации на n8n

Четыре рабочих сценария: приём заявок с проверкой, контент-конвейер,
дедупликация лидов и ежедневная отчётность.

Сайт собран на статике: `index.html`, `i18n.js` (переводы), `vendor/` (GSAP),
`screenshots/` (снимки канвы n8n). Сборка не нужна — папка и есть репозиторий.
